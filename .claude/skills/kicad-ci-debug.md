# KiCad CI Export Workflow Debugging

Debug and fix the KiCad image export GitHub Actions workflow. Use when CI fails on "Export KiCad Images" workflow or when commits trigger export failures.

## Workflow Overview

The export workflow is defined in `.github/workflows/export-images.yml` and uses a reusable workflow from `zeulewan/shared-workflows/.github/workflows/export-kicad-images.yml@main`.

### Trigger Conditions
- Push to `main` branch with changes in `kicad/**`
- Manual `workflow_dispatch`

### What It Does
1. Pulls KiCad 9.0 Docker image
2. Clones KiCad 3D model library
3. Exports: schematic SVG, PCB SVGs, 3D renders (PNG), STEP model
4. Crops rendered images with ImageMagick
5. Commits and pushes updated images

## Common Failures and Fixes

### 1. Gitignore Blocking Files

**Symptom:** `git add images/*` fails with "paths are ignored by .gitignore"

**Example error:**
```
The following paths are ignored by one of your .gitignore files:
images/board.step
hint: Use -f if you really want to add them.
```

**Fix:** Add exceptions in `.gitignore`:
```gitignore
# Large binaries
*.step
# Allow exported board.step in images
!images/board.step
```

### 2. Race Condition / Rebase Conflicts

**Symptom:** `git pull --rebase` fails with merge conflicts on binary files

**Example error:**
```
CONFLICT (content): Merge conflict in images/board.front.png
error: could not apply ... Update KiCad images
```

**Cause:** Another commit was pushed while workflow was running

**Fix:** Add concurrency control to workflow:
```yaml
concurrency:
  group: export-kicad-images-${{ github.ref }}
  cancel-in-progress: true
```

### 3. No Changes to Commit

**Symptom:** Workflow outputs "No changes to commit" but doesn't fail

**This is normal** - if images haven't changed, there's nothing to commit.

## Debugging Commands

### Check recent workflow runs
```bash
gh run list --limit 5
```

### View failed run details
```bash
gh run view <run-id>
```

### Get detailed job logs
```bash
gh api repos/zeulewan/singingcard/actions/runs/<run-id>/jobs --jq '.jobs[0].id' | \
  xargs -I {} gh api repos/zeulewan/singingcard/actions/jobs/{}/logs
```

### Manually trigger workflow
```bash
gh workflow run export-images.yml
```

### Watch workflow progress
```bash
gh run watch <run-id>
```

## Files Generated by Workflow

| File | Description |
|------|-------------|
| `images/sch.svg` | Schematic SVG |
| `images/pcbf.svg` | PCB front SVG |
| `images/pcbb.svg` | PCB back SVG |
| `images/board.front.png` | 3D render front (cropped) |
| `images/board.back.png` | 3D render back (cropped) |
| `images/board.step` | 3D STEP model |
